# Real and Fake Face Detection Using Deep Learning

## Project Description
This project aims to classify real and fake face images using deep learning techniques.

## Tools and Technologies
- Python
- TensorFlow
- Keras
- Jupyter Notebook

## Dataset
Real and Fake Face Detection Dataset from Kaggle

## Models Used
- Custom CNN
- MobileNetV2

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
